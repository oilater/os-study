## 요약

- **운영체제의 정의**: 사용자에게 편리한 인터페이스 환경을 제공하고, 컴퓨터 시스템의 자원을 효율적으로 관리하는 소프트웨어
- **운영체제의 역할과 목표**: 자원 관리 ↔ 효율성, 자원 보호 ↔ 안정성, 하드웨어 인터페이스 제공 ↔ 확장성, 사용자 인터페이스 제공 ↔ 편리성
- **운영체제의 역사**: 진공관(1940s) → 일괄 작업(1950s) → 대화형(1960s 초) → 시분할(1960s 후) → 분산(1970s) → 클라이언트/서버(1990s) → P2P·클라우드·IoT(2000s)
- **운영체제의 구성**
  - 인터페이스: 사용자·응용 프로그램과 커널 사이에서 명령을 전달하고 결과를 돌려줌
  - 커널: 운영체제의 핵심 기능 모음
- **시스템 호출과 드라이버**: 응용 프로그램 ↔ 커널은 시스템 호출, 커널 ↔ 하드웨어는 드라이버
- **커널의 종류**
  - 단일형: 핵심 기능 모듈들이 구분 없이 하나로 구성
  - 계층형: 비슷한 기능의 모듈을 계층으로 묶고, 계층 간 통신으로 구현
  - 마이크로: 프로세스 관리, 메모리 관리, IPC 관리 등 가장 기본적인 기능만 제공
- **가상머신**: OS와 응용 프로그램 사이에서 같은 실행 환경을 만들어, 코드 하나로 여러 OS에서 돌게 한다.
- **운영체제의 계보**: 멀틱스 → 유닉스 → BSD·System V → 마하 → macOS·iOS / GNU + 리눅스 → 안드로이드 / MS-DOS → 윈도우

---

## 느낀 점

- 운영체제의 역사를 읽는 게 굉장히 재밌었다.
- 커널이 단일형·계층형·마이크로 구조로 나뉜다는 걸 처음 알았다.
- 드라이버가 커널이 실행될 때 함께 실행된다는 점 등 새로 알게 된 것이 많았다.
