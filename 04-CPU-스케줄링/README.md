# 04. CPU 스케줄링

CPU 스케줄링은 어떤 작업에 CPU를 배정할지 결정하는 일이다. 어떤 프로세스에 CPU를 먼저 주느냐에 따라 시스템의 효율이 달라지므로, 작업의 형평성과 효율성을 결정하는 중요한 일이다.

## 목차

1. [스케줄링의 개요](./01-스케줄링의-개요.md)

---

## 요약

- **CPU 스케줄러**: 프로세스가 생성되어 종료될 때까지 모든 상태 변화를 조정한다. 식당 관리자에 비유된다.
- **스케줄링 단계**
  - 고수준(장기): 시스템에 받아들일 작업 수를 정한다. 멀티프로그래밍 정도를 결정한다.
  - 중간 수준: 활성 프로세스 일부를 보류시켜 과부하를 막는다.
  - 저수준(단기): 어떤 프로세스에 CPU를 줄지 정한다.
- **스케줄링의 목적**: 공평성, 효율성, 안정성, 확장성, 반응 시간 보장, 무한 연기 방지. 단, 안정성과 효율성을 위해 공평성은 일부 희생된다.

---

## 느낀 점

- 이전에는 활성 프로세스에 CPU를 할당하는 저수준 스케줄링만 알고 있었다. 작업을 시작할지 정하는 고수준 스케줄링과, 과부하가 생기면 일부를 보류시키는 중간 수준 스케줄링도 있다는 걸 새로 알았다.
