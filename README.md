# OS Study

최근 회사에서 Windows 데스크톱을 쓰게 되면서 HDD에 설치된 운영체제를 SSD로 옮겨보기도 하고, BIOS 화면을 처음으로 들여다보고, SSD와 RAM 카드를 직접 조립해 보는 등 재미있는 일을 많이 겪었습니다.

맥북만 썼다면 해보기 어려웠을 일들을 하다 보니 컴퓨터 구조와 운영체제가 궁금해졌고, 마침 『쉽게 배우는 운영체제』라는 책을 접하게 됐습니다. 읽어본 책들 중 운영체제를 가장 쉽고 자세하게 설명해서 많은 도움이 됐습니다.

이 레포는 책을 읽으며 직접 정리한 노트를 바탕으로 Claude와 함께 다듬은 내용입니다. (직접 다듬기는 귀찮음)

운영체제를 이해하는 데 저와 여러분 모두에게 도움이 되길 바랍니다 😊
